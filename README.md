# ⚡ EYAD Trading Bot & Quantitative AI Terminal

**تنبيه بحثي هام:** هذه المنظومة هي أداة بحثية ومحاكاة بحتة (Research & Simulation Tool). في اختبارات الأداء التاريخي، الاستراتيجية المطبقة لم تتفوق على استراتيجية الشراء والاحتفاظ (Buy & Hold) بعد احتساب العمولات. لذلك، **تم إيقاف التنفيذ الحي (Live Execution) بشكل دائم** ولا ينصح بالاعتماد على النظام في التداول الحقيقي.

منظومة تداول كمية ذكية وتحليل فوري لأسواق العملات الرقمية (BTC, ETH, PAXG) مدعومة بخوارزميات صيد السيولة وموجات إليوت والمساعد الصوتي الذكي.

---

## 🚀 كيفية تشغيل المشروع على جهازك (How to Run Locally)

المشروع عبارة عن تطبيق ويب متكامل (**Full-Stack Web Application**) مبني باستخدام **React + TypeScript + Vite + Express**.

### المتطلبات الأساسية (Prerequisites):
- تثبيت **Node.js** (الإصدار 18 أو أحدث) على جهازك من: [nodejs.org](https://nodejs.org)

### خطوات التشغيل (3 خطوات بسيطة):

1. **تحميل المشروع أو استنساخه (Clone/Download):**
   ```bash
   git clone https://github.com/eyadghoneim/eyad.git
   cd eyad
   ```

2. **تثبيت الحزم والمكتبات (Install Dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل خادم التطوير (Run Dev Server):**
   ```bash
   npm run dev
   ```

4. افتح المتصفح على الرابط:
   👉 **`http://localhost:3000`**

## 🌟 مميزات المنظومة (Key Features):
- 📊 **محرك اختبار تاريخي (Backtesting Engine)**: لاختبار قواعد الدخول والمخاطرة بدقة وشفافية كاملة.
- 🎯 **خريطة التصفيات**: رصد كتل تصفية عقود الشورت واللونج اللحظية وتحديد اتجاه السعر.
- 🤖 **المحفظة التجريبية (Paper Trading Simulator)**: تنفيذ افتراضي لغرض المحاكاة والدراسة فقط.
- 🧠 **محرك التعلم الذاتي (Self-Learning AI)**: تسجيل أداء الصفقات وتفادي فترات التذبذب العالي.
- 🎙️ **مساعد التداول الصوتي الذكي**: محادثة وتحليل صوتي لحظي.

## 🛡️ إعدادات الحماية والتخزين (Security & Persistence Architecture)

أضف هذه المتغيرات إلى ملف `.env` عند التشغيل والنشر:

```env
GEMINI_API_KEY=your_key_here
APP_URL=https://your-domain.example
BOT_ADMIN_TOKEN=change-this-to-a-long-random-secret
```

- **`BOT_ADMIN_TOKEN`**: إلزامي لحماية نقاط الإدارة والتحكم الحساسة (`/api/bot/*`).
- **بنية التخزين والأمان (Firestore & Local Fallback)**:
  - قواعد Firestore محددة بـ (`allow read, write: if false;`) لمنع أي قراءة أو كتابة مباشرة وغير موثقة من المتصفح.
  - جميع عمليات الحفظ والمزامنة للإشارات وحساب المحاكاة التجريبية تتم **حصرياً من جهة السيرفر (Server-Side)** مع دعم التخزين المحلي (Local File Persistence) كـ Fallback عند التشغيل المستقل.
  - محرك الباك تيست يعتمد على بيانات Binance التاريخية الرسمية، ويقوم بتمييز أي بيانات مولدة بشارة `SYNTHETIC_FALLBACK` لضمان الشفافية العلمية.
